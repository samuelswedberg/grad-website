# grad-website

Next.js portfolio for Samuel Swedberg.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS v4
- `shadcn/ui`-compatible structure
- GSAP for the WebGL hero interaction

## Getting started

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Structure

- `app/` route files
- `components/` shared UI and layout components
- `components/ui/` shadcn-style UI location
- `lib/` site data and utilities
- `public/media/` portfolio images

## Routes

- `/` homepage with the `revolution-hero`
- `/projects`
- `/projects/sim-racing-system`
- `/about`
- `/demo`
